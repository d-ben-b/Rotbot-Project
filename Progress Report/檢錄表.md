# 2026 隊伍檢錄表


## 參賽隊伍機器人本體 - 簡述

| 項目 | 內容說明 / 規格 |
| :--- | :--- |
| **隊伍名稱** | 嘻諧們 |
| **尺寸與體重** | 尺寸 $50 \times 50 \times 60\text{ cm}$，重量 $12\text{ kg}$。 |
| **安全機制** | 開關安裝在主電源線路上（設置於砲塔最上方，確保可由拍擊穩定觸發緊急停止），按下後即馬達斷電。 |
| **遙控器** | 飛智沙漠狐遊戲手柄，手柄與電腦採用 USB 連線。遙控時的操作命令由手柄下達，並透過電腦和路由器作為轉發給 Orin Nano 的工具。另外，開機歸零時會使用電腦，但沒有其他操控指令。 |
| **燈具或揚聲器規格** | 燈具規格：5mm 低亮度 LED 狀態指示燈（紅光/綠光，亮度 $\le 100\text{ mcd}$）。未使用揚聲器。 |
| **控制器平台** | NVIDIA Jetson Orin Nano Super 與 NUCLEO-G474RE 核心控制板。 |
| **驅動單元** | 1. 麥克納姆輪底盤：4 顆車輪編碼馬達<br>2. 水平旋轉機構：42BYGH60 步進馬達 (1 顆)<br>3. 俯仰旋轉機構：57 一體式閉環步進馬達 (2 顆)<br>4. 發射摩擦輪機構：775 直流馬達 (2 顆)<br>5. 彈倉分流機構：N20 小型減速馬達 (6 顆)<br>6. 推彈模組：TT 馬達 (1 顆) |
| **傳動單元** | 1. 底盤：直驅 (與聯軸器連結)<br>2. 水平旋轉：21齒太陽齒輪、36齒行星齒輪、93齒外環齒輪 (行星齒輪組，減速比 5.43:1)<br>3. 俯仰旋轉：T20-T60 傳動皮帶輪 (減速比 3:1)<br>4. 推彈機構：曲柄滑塊機構 (移動行程 40mm)<br>5. 彈倉分流：小型馬達擋桿機構 |
| **承載車架平台** | 3030 與 3060 鋁擠型結構，搭配三角連結塊組裝為矩形主支架，車身結構多處採用 5mm 壓克力板、2020 鋁擠型與 3D 列印件組合。 |
| **AP 功率** | 符合國家通訊傳播委員會（NCC）《低功率射頻器材技術規範》（LP0002）室內 WLAN 裝置標準（2.4GHz / 5GHz 頻帶最大傳導輸出功率 $\le 1\text{ W}$ / $1000\text{ mW}$）。市售原廠路由器符合相關法規檢驗，惟原廠未於規格表中提供具體 mW / dBm 輸出功率數值。 |
| **通訊設備** | 自備無線路由器 (連接操控電腦與 Orin Nano 通訊用)、USB 數據傳輸。 |
| **AI 技術應用** | 1. YOLO (yolo11n) 圓孔辨識演態定位：辨識網框 12 個圓孔位置 (一般孔、加分孔、亮燈加分孔) 並算出瞄準角度。<br>2. PnP 演算法結合 RK4 彈道模型計算發射角度與落點。<br>3. 開發階段應用：使用大型語言模型 (Claude) 產生 Web 比賽操控介面並協助控制板腳位分配與配線疑難排解。 |
